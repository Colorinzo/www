1. Экспорт файла data.json (для GitHub Pages / Vercel)

Если ты хостишь сайт как статику бесплатно, добавь новые приложения через редактор, нажми «Скачать data.json» и замени файл в папке сайта — все посетители увидят обновления.

2. Прямая публикация в облако без бэкенда (JSONBin.io)

Хочешь постить прямо с телефона из браузера без перезаливки файлов? Создай бесплатный Bin на jsonbin.io, вставь Bin ID и Master Key ниже. При нажатии «Опубликовать» база будет обновляться у всех посетителей автоматически.
